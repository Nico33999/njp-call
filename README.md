# NJP Call - Assistant d'accueil téléphonique IA

## Description
Application web pour configurer et simuler un assistant IA d'accueil téléphonique.

## Développement
- `pnpm dev` pour lancer en mode développement
- `pnpm build` pour construire l'application

## Déploiement sur Vercel
1. Connectez votre repo GitHub à Vercel
2. Vercel détectera automatiquement le projet Vite
3. Déployez !

Le site est maintenant prêt pour la production.
